# 实验设计、指标口径与对比基线深度解剖手册

> **目的**：让你对实验底座、数据划分、攻击构造、指标定义和每一个对比基线的底层代码机制了如指掌，评委无论抠到多细的实验细节都能对答如流。

## 一、实验底座与数据防泄露铁律

### 1. 底座配置（`OPV2V + HEAL`）
* **数据集**：`OPV2V`（ICRA 2022），包含同步采集的多车 64 线激光雷达点云、4 路环视相机 RGB 图像、高精度车辆位姿与 3D 目标边界框真值。
* **冻结跨模态框架**：`HEAL`（ICLR 2024 官方开源预训练权重，全程参数冻结、不微调检测头）：
  - **本车（Ego，`j = 0`）**：`m1` 64 线激光雷达 + `PointPillars` 编码器；
  - **协作者（Collab）**：
    - 2 车异构对模式：分别测试 `m1`（64 线 LiDAR-PointPillars）与 `m2`（4 目环视 Camera-LSS）；
    - 多车混合车队模式（`mixed`）：本车固定 `m1`，协作者按 `m2, m1, m2, m1...` 严格交替（因此 **3 车场景 = 1 雷达本车 + 1 摄像头协作车 + 1 雷达协作车**）。
  - **传输层协议特征**：`heter_feature_2d ∈ R^{64×256×256}`，对应 BEV 物理范围 `[-102.4, 102.4]^2 m`，单网格空间分辨率 **`0.8 m`**。

### 2. 数据划分与零泄露规范
| 数据分片 | 规模 | 用途 | 泄露隔离规则 |
| :--- | :---: | :--- | :--- |
| **`FIT-11`** | 11 条父序列（2,312 帧） | 离线标定 `BUD-Fusion` 条件分位数表；重训 `HetShield` 64ch ConvGRU | **仅使用无攻击数据**（零攻击样本训练） |
| **`DEV-8` (`Dev-320`)** | 8 条未见父序列（320 帧） | 当前所有开题汇报实测主表与消融验收 | 按父序列与 `FIT-11` 100% 严格互斥；含 1 协作车 41 帧 / 2 协作车 145 帧 / ≥3 协作车 134 帧 |
| **`opv2v_val`** | 6 序列（965 帧） | 最终封测前的外部门限重标定 | 独立验证集 |
| **`opv2v_test`** | 16 序列（2,170 帧） | 大论文/顶刊投稿一次性最终封测 | **目前绝对封存未触碰** |

* **统计严谨性**：所有关键指标差值均报告 **2,000 次按父序列整块抽样（Block-Bootstrap）95% 置信区间**，规避连续视频帧时间相关性带来的假显著。

## 二、6 类白盒特征攻击的精确构造机理

所有特征攻击均在协作者发送的协议特征 `heter_feature_2d` 上构造（白盒梯度来自冻结 `HEAL` 融合与检测头，代表最强威胁上限）：

| 攻击类型 | 攻击范围 | 扰动预算 | 核心攻击目标与直观效果 |
| :--- | :---: | :---: | :--- |
| **1. 全局特征对抗扰动 (`Global PGD`)** | 整张 `256×256` 特征图 | `0.5σ / 1.0σ / 2.0σ` 及 `ε=4.0`（按本车特征标准差缩放） | 全面压低真实目标置信度并制造全图噪声，让无防御 AP 从 `82.5%` 暴跌至 `28.7%`（3 车 `92.2% → 14.8%`） |
| **2. 定向目标移除 (`Targeted Object Removal`)** | 仅 2 辆真实目标周围 `5×5` 网格（`4m×4m`） | `1.0σ` | 注入反向梯度特征强行抵消本车真车响应，隐蔽抹除真车（无防御下 3–6 车移除成功率 `58.6%`） |
| **3. 虚假目标伪造 (`Targeted Object Fabrication`)** | 仅 2 处空旷区 `5×5` 网格 | `2.0σ` | 在空地注入高响应假车特征诱导急刹误检（无防御下 3–6 车伪造成功率高达 `96.2%`） |
| **4. 遮挡区目标伪造 (`Occluded-Region Fabrication`)** | 仅在本车激光射线被遮挡区域选 2 处 | `2.0σ` | 专门检验防御的盲区保护机制是否留有“遮挡区免检后门” |
| **5. 近场目标移除 (`Near-Field Removal`)** | 距协作者 `0–6 m` 近场真车 | `2.0σ` | 针对摄像头 LSS 近场奇异高幅带发起擦除，验证 `0–6 m` 独立成档不豁免的安全性 |
| **6. 双攻击者并发压测** | 4–6 车混合车队同时指定 2 名恶意协作者 | 同上 | 检验多恶意节点并发下防御是否被多数票或累加扰动击穿 |

## 三、核心评价指标的精确计算口径

1. **`AP@0.5`（3D 检测平均精度）**：
   - 预测 3D 框与真值 3D 框在 BEV 平面 IoU ≥ `0.5` 判定为命中，计算 Precision-Recall 曲线下面积。
   - **局限**：定向局部攻击每帧只改 2 辆车，全图还有十几二十辆正常车，因此全图 `AP@0.5` 会被大量正常车摊薄（看着只掉 3%–5%）。
2. **`ASR`（定向攻击成功率，越低越安全）**：
   - 专门针对**被攻击者动手脚的那批有效目标**（3–6 车单攻击者共统计 `1,082` 个移除目标、`1,110` 个伪造目标，匹配半径 `3.0 m`）：
     - **目标移除 ASR**：原本无攻击时能检出、受攻后成功消失的被攻击真车占比；
     - **目标伪造 ASR**：在攻击注入的空地中心 `3.0 m` 内成功冒出高置信虚假检测框的占比。
   - **价值**：直击局部攻击是否真正得逞（无防御 `58.6% / 96.2%` → 本文 **`4.3% / 32.1%`**）。
3. **客观盲区召回率（583 辆纯他车盲区 GT）**：
   - **严格定义**：在 Dev-320 全部真值车辆中，剔除本车原点 `r < 2.5 m` 自身框后，满足 **“本车激光雷达落在该车上的点数 ≤ 5”且“纯本车单车推理漏检”** 的真实车辆（共 **583 辆**）。
   - 纯单车 `Ego-Only` 对这 583 辆车的召回率严格为 **`0.00%`**；任何高于 `0%` 的召回全部是协作车带来的纯补盲价值！
4. **单帧推理延迟（CUDA Event 精确计时）**：
   - RTX 4090 独占运行 10 帧预热后统计 100 帧端到端接收端推理耗时（`10 Hz` 车载实时红线 = `100 ms`）：
     - 无防御 `21.8 ms` | `LUCIA` `22.4 ms` | `HetShield` `24.5 ms` | **`BUD-Fusion` `69.9 ms`（P95 `79.3 ms`，1 车 `48.0 ms`）** | `ROBOSAC` `190.9 ms`（P95 `403.7 ms`，严重超时）。
     - `BUD` 内部拆解：物理分档 `2.34 ms`（3.3%）+ 逐车审计 `40.67 ms`（58.2%，点三并行优化大头）+ 门控构建 `3.94 ms`（5.6%）+ 门控融合与检测头 `22.95 ms`（32.8%）。

## 四、5 大对比基线源码级解剖与失效根因速查表

| 基线方法 | 来源 | 核心算法机制（源码核实） | 在跨模态异构车队中的真实表现与根因 |
| :--- | :---: | :--- | :--- |
| **`ROBOSAC`** | ICCV'23 | 随机采样协作者子集反复融合出框，计算融合框与本车框集合的 **2D Jaccard 相似度**（默认门限 `0.3`）寻找共识子集 | • **长处**：3 车无攻击 `92.2%` 零掉点，全局 PGD 救回 `80.1%`；<br>• **3 大硬伤**：① 需 ≥2 协作车（2 车不可用）；② 局部只改 2 辆车时整图框 Jaccard 仍高达 `0.65~0.85 >> 0.3`，第一步即全放行（**ASR `57.9% / 95.7%`**）；③ 反复重推理导致均值 **`190.9 ms`** 超实时红线。 |
| **`LUCIA`** | USENIX Sec'25 | 官方无阈值公式：对齐特征经 `avg_pool2d(32)` 压缩 + L2 归一化 → 算两两 L1 距离与集群中位数偏差 → `1 - softmax` 赋信任权 | • **同构有效证公平**：同帧无攻击混合车队里给诚实雷达信任 **`97.4%`**；<br>• **异构失效根因**：雷达车天然聚簇，诚实摄像头因深度误差 L1 距离大，同帧信任暴跌至 **`39.4%`**（中位数 `15.5%`），4–6 车无攻击 AP 暴跌 **`-12.3%`**；2 车直接退化纯单车；`32×32` 大池化抹平局部篡改，**ASR 仍达 `33.2% / 63.5%`**。 |
| **`CP-uniGuard`** | arXiv'25 | PASAC 子集共识 + CCLoss + `OnlineAdaptiveThreshold` 双滑窗在线阈值 | **源码核查（`adaptive_threshold.py` L42–46）**：全车队仅维护单一全局标量门限，不按传感器模态或观测条件分档，仍为整车级剔除。 |
| **`HetShield`** | arXiv'26 | 64ch ConvGRU 一步时序预测误差 $\tau_k$ + 跨车平均余弦不一致 $1-\sigma_k$，合成整车异常分 $s_k = 0.5\tau_k + 0.5(1-\sigma_k)$ 与单一门限对比 | • **长处**：单模态全局 PGD 区分度极高（`m2` `AUROC = 0.976`，合理阈值 `0.438` 下检出 `97.5%`）；<br>• **2 大边界短板**：① 跨模态空间一致性天然错位（`m1 = 0.881` vs `m2 = 0.390`），导致无攻击异常分均值 `0.171 vs 0.379`——严阈值 `0.30` 误杀诚实 `m2` **`98.1%`**，放宽至 `0.438` 后对 `m1` 雷达攻击检出全部归零 **`0.0%`**；② 全图平均稀释局部微簇，局部移除/伪造原始 `AUROC` 仅 **`0.51~0.66`**。 |
| **`WholeDrop`**（整车拒绝） | 控制变量消融基线 | 采用与 `BUD-Fusion` **完全相同的帧级条件异常分 `score_t4`**，但处置改为“超 `1.0` 即整车清零、否则全放行” | • **证明细粒度软门控净收益**：检出帧一刀切踢光盲区（盲区召回暴跌至 **`19.7% / 43.9%`**）；未超整帧 `1.0` 的隐蔽局部帧原样放行，反而导致局部攻击 **ASR 仍高达 `14.8% / 52.9%`**（显著差于本文 **`4.3% / 32.1%`**）。 |
