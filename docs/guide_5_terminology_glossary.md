## 一、协同感知基础与传感器底座

| 名词 / 缩写 | 一句话大白话解释 | 在本课题里的具体含义 |
| :--- | :--- | :--- |
| **V2X / V2V** | 车与外界（V2X）/ 车与车（V2V）无线通信 | 本车接收邻车广播位姿与感知特征的通信渠道 |
| **BEV（鸟瞰图）** | 从正上方往下看的俯视二维网格地图 | 本课题 BEV 网格为 `256×256`，覆盖 `[-102.4, 102.4]² m`，每格 `0.8 m` |
| **跨模态异构协同** | 车队里不同车装的传感器不一样（不是全激光雷达） | 本课题聚焦 **64 线激光雷达车（`m1`）+ 4 目环视摄像头车（`m2`）** 混编 |
| **PointPillars** | 把 3D 激光点云竖着切成一根根“柱子”压缩成 BEV 特征图的经典雷达网络 | 本课题中 `m1` 激光雷达车使用的编码骨干 |
| **LSS（Lift-Splat-Shoot）** | 给 2D 相机图像逐像素预测深度分布，再把图像特征“抬升投射”到 BEV 网格的经典视觉网络 | 本课题中 `m2` 四路环视摄像头车使用的编码骨干，因单目猜深度导致远距径向误差大 |
| **中层特征融合 / 共享协议特征** | 不传原始大点云/原图，也不只传最后几个框，而是传神经网络中间提取的压缩 BEV 特征图 | `HEAL` 传输层特征维度为 `64×256×256`，兼顾信息量与通信带宽 |
| **HEAL（ICLR'24）** | 主流异构协同感知框架，能把不同传感器/网络的特征对齐到同一共享 BEV 空间 | 我们采用的**官方冻结底座**，无攻击下 3 车融合 AP 达 `92.2%`，但无安全防御 |
| **冻结模型 / 冻结检测头** | 直接使用预训练好的感知网络与出框头，**不修改、不重训它的权重** | 证明我们的安全防御是即插即用外挂层，不靠改检测网络作弊 |
| **OPV2V / V2V4Real** | 协同感知最常用的两大开源基准数据集（OPV2V 为仿真，V2V4Real 为真实道路采集） | 当前核心实验在 OPV2V 上完成，研究内容三将在 V2V4Real 做跨集验证 |
| **TCB（可信计算基）** | 系统中你默认绝对可信、不会被黑客控制的那部分硬件和软件 | 本课题的 TCB 为**本车自身（64 线雷达 + 本地推理模型）**，其余协作车均不可信 |

## 二、攻击模型与安全威胁

| 名词 / 缩写 | 一句话大白话解释 | 在本课题里的具体含义 |
| :--- | :--- | :--- |
| **白盒 / 黑盒攻击** | 白盒 = 攻击者知道本车模型结构和梯度（最强威胁）；黑盒 = 攻击者不知道 | 我们用最强白盒攻击评测防御下限，能防住白盒就能兜底更弱的黑盒 |
| **Global PGD（全局特征对抗扰动）** | 用梯度优化给整张特征图铺满精心计算的对抗噪声 | 让无防御检测彻底瘫痪（3 车 AP 从 `92.2%` 崩至 `14.8%`） |
| **Targeted Object Removal（定向目标移除）** | 只篡改 2 辆真车周围 `5×5` 小块特征，强行抵消本车响应让真车凭空消失 | 极其隐蔽危险，无防御下 3–6 车移除成功率达 `58.6%`，本文压至 **`4.3%`** |
| **Targeted Object Fabrication（虚假目标伪造）** | 只在 2 处空地注入 `5×5` 假车特征，诱导本车以为前面有车而急刹 | 无防御下 3–6 车伪造成功率高达 `96.2%`，本文压至 **`32.1%`**（全场最低） |
| **Occluded-Region Fabrication（遮挡区伪造）** | 专门挑本车被挡住看不见的盲区造假车 | 专门用来测试盲区保护机制有没有留下“免检后门” |
| **Near-Field Removal（近场目标移除）** | 专挑距摄像头车 `0–6 m` 极近处发起移除攻击 | 验证 `0–6 m` 独立分档标定不会成为安全豁免漏洞 |
| **AdvGPS（全局位姿虚报）** | 恶意协作车谎报自己的 GPS 经纬度或车头朝向（偏 `1.5~8 m`） | 导致整张特征图投影错位，所有车位置全歪 |
| **PosePert（局部单车偏移）** | 整车位姿没撒谎，但悄悄把某 1~2 辆目标车的位置挪歪 | 干扰全局位姿配准，或制造局部位置错乱，由 `LOCAL_FLAG` 捕获 |
| **持续亚米级微偏置** | 每帧只悄悄偷偏 `0.5~0.8 m`，单帧混在正常 GPS 误差里躲避检查 | 靠世界坐标系连续 $L=5$ 帧均值检验识破（仿真 `AUROC = 0.98`） |
| **弱观测方向偏移（沿 $v_{\min}$）** | 攻击者故意沿着几何约束最松的那个方向（如排成一排车时的前后方向）偷偏 | 由 Fisher 信息矩阵条件数诊断，属几何配准原理边界 |
| **复合攻击** | 同时发动空间位姿篡改 + 中层特征篡改 | 研究内容三跨层协同接口（接口 A + 接口 B）的重点防御对象 |
| **Attack-Agnostic（零攻击样本标定）** | 防御器训练/标定阶段**完全不看任何攻击样本**，只用正常无攻击数据 | 避免针对某一种攻击过拟合，天然泛化到未知新型攻击 |

## 三、研究内容一：跨模态位姿检测与鲁棒对齐（`AnisoSafe-Align`）

| 名词 / 缩写 | 一句话大白话解释 | 在本课题里的具体含义 |
| :--- | :--- | :--- |
| **$SE(2)$ 位姿** | 平面内的刚体变换，包含 3 个自由度：横坐标 $x$、纵坐标 $y$ 和航向角 $\theta$ | 车端 BEV 坐标对齐只需校正二维平移与平面朝向 |
| **极坐标各向异性（径向 / 横向）** | 不同方向误差大小不一样：沿视线前后叫**径向**，垂直视线左右叫**横向** | 实测摄像头 45–60 m 径向误差达 **`2.24 m`**，是横向的 `1.65×`、雷达的 **`7.2×`** |
| **协方差矩阵 $\Sigma_n$** | 用一个 2×2 矩阵描述二维误差椭圆的胖瘦大小和旋转朝向 | 接收端按模态与距离查表自建，**绝不采信协作者自报方差** |
| **马氏距离（Mahalanobis）** | “除以各自方向误差方差”后的加权距离，误差大的方向权重小、误差小的方向权重大 | 实现沿视线“径向宽容、横向收紧”的核心数学工具 |
| **截断匈牙利匹配** | 在多车之间做一对一最优配对，且超过卡方门限的离谱远距离直接截断不强行硬配 | 得到当前帧可靠的共视车辆匹配对 $\mathcal{M}_{\text{cur}}$ |
| **Fisher 信息矩阵 $H_{\text{obs}}$ 与条件数 $\kappa$** | $H_{\text{obs}}$ 衡量共视车阵型对位姿的约束强度；条件数 $\kappa = \lambda_{\max}/\lambda_{\min}$ 越大说明阵型越扁/越接近共线 | 用于主动诊断窄锥共线等“弱观测风险”，触发 MAP 阻尼防发散 |
| **GNC-TLS（渐进非凸截断最小二乘）** | 一种经典的抗离群点优化算法：由松到紧迭代，自动把歪得离谱的外点权重压成 `0` | 面对 `33%` 局部挪车外点，仍把配准误差稳守在 `0.34~0.37 m` |
| **MAP 阻尼（最大后验阻尼）** | 在优化目标里加一个拉回先验的正则项 $\|\Delta T\|_{\Lambda_{\text{prior}}}^2$ | 当共视车仅 1~2 辆或共线时防止矩阵求逆发散（2 车误差压至 `0.45 m`） |
| **内点率 $\rho_{\text{in}}$** | 匹配上的车辆中，经过鲁棒优化后被认定为正常一致（权重 $w_k > \tau_w$）的比例 | 内点率过低说明整车位姿严重错乱，直接触发 `REJECT` |
| **世界系防污染短窗检验** | 把连续 $L$ 帧的位移校正量转到固定地面坐标系求均值；被拒止的坏帧不写入缓存 | 正常随机漂移正负抵消，恶意持续偷偏会累积超标；防坏帧污染历史窗口 |
| **一次性无损投影** | 先在局部特征上抽框判完位姿，放行后再按校正位姿只做 1 次双线性特征变换 | 消除“先按错位姿投影、再二次旋转”带来的插值模糊掉点 |

## 四、研究内容二：跨模态异构可信特征融合（`BUD-Fusion`）

| 名词 / 缩写 | 一句话大白话解释 | 在本课题里的具体含义 |
| :--- | :--- | :--- |
| **视线遮挡包络 $r_{\text{occ}}(\theta)$ 与 $\operatorname{los}(x)$** | 按本车 64 线雷达每个方位角最近的障碍物画一圈遮挡边界，边界之外就是视线被挡住 | $\operatorname{los}(x) < 0.50$ 直接判定为 **`Occluded`（遮挡盲区）** |
| **预期激光点数 $N_{\text{exp}}(x)$** | 按 64 线雷达线束几何公式，算出在位置 $x$ 放一辆标准车预期能打中多少个激光点 | 区分 **`Clear`（清晰，≥73.85 点，约 40 m 内）** 与 **`Sparse`（远距稀疏）**，根治远距补盲误杀 |
| **前景/空地双分档（`fg / bg`）** | 把网格按协作车有没有前景响应分成“有车格 `fg`”和“空地格 `bg`”分别标定门槛 | 防止占全图 99% 的空地拉低门槛误杀盲区真车，同时提升遮挡区伪造检出（`AUROC 0.908`） |
| **多尺度特征余弦偏差 $d_{\text{feat}}$** | 在特征金字塔 L0/L1/L2 三个分辨率上算本车与协作车特征向量的方向夹角差（$1-\cos$） | 综合捕捉细粒度局部畸变与大范围全局语义异常 |
| **$5\times 5$ 容差有向语义池化** | 先在周围 `5×5` 格（`±1.6 m`）取最大值再做单向减法，分出移除项 $d_{\text{drop}}$ 和新增项 $d_{\text{add}}$ | 吸收摄像头正常微小定位抖动；把“擦除本车真车”和“盲区新增补盲”严格区分开 |
| **条件分位校准（`p95 / p98 / p99.9`）** | 用离线无攻击数据里 95%/98%/99.9% 的正常上限作为“及格线”，只算超出及格线的部分 | 彻底实现跨模态对称（诚实雷达与摄像头误报均稳控在 `3%–5%`） |
| **膨胀池化（`r_dil = 3` / `7×7` MaxPool）** | 把检测出的异常点向外扩一圈（半径 2.4 m） | 让局部门控完整包住整辆被篡改车辆及其卷积感受野 |
| **细粒度空间软门控 $g_i(x)$** | 用指数平滑衰减 $e^{-\beta E}$ 把异常区权重压近 `0`、正常区保持 `1` | 相比 `0/1` 硬挖洞避免卷积边缘伪影；相比整车拒绝保住其余区域盲区补全 |
| **整车级高门限回退（`frame_high_tau`）** | 给整帧总分设一道极高的安全红线（`m1=1.495, m2=1.610`，无攻击误触发 `0.0%`），超线直接关闭整车 | 专门在全局强 PGD 攻击下托底拦截，额外挽回 `+3.5%~+6.0%` AP |
| **权重差额归还本车** | 协作车被软门控扣掉的那部分融合权重，原封不动加回到可信本车权重上 | 保证每个网格权重总和恒等于 `1`，防止特征能量整体衰减 |

## 五、研究内容三：系统集成与调度（方案 3A）

| 名词 / 缩写 | 一句话大白话解释 | 在本课题里的具体含义 |
| :--- | :--- | :--- |
| **残余位姿不确定度传递（接口 A）** | 前级把剩余配准误差协方差通过雅可比矩阵映射到各网格，叠加到后级特征校准基准 | 缓解窄锥微残差诱发的跨层连锁误报，且设截断上界防绕过 |
| **异常目标区域移交（接口 B）** | 把前级 `LOCAL_FLAG` 标出的歪车区域 $\mathcal{M}_{\text{local}}$ 直接乘进后级软门控 | 实现对“正常位姿 + 局部单车偏移”复合攻击的跨层联合精准静音 |
| **级联误报** | 前一级留下的微小正常误差传到下一级，被下一级当成严重攻击报警 | 串联两级防御时最常见的工程坑，由接口 A 专门治理 |
| **拒止早停与指数退避** | 前级判 `REJECT` 直接跳过投影和融合；连续作恶的节点暂停接收其广播并拉长静默期 | 既省算力又防恶意节点发垃圾包占满通道（DoS） |
| **批量张量并行审计** | 把当前逐车循环跑审计（占 `40.7 ms`）改成把多辆协作车拼成一个 Batch 在 GPU 一次性并行算 | 研究内容三将单帧延迟进一步压进 `40~50 ms` 的核心工程手段 |

## 六、评价指标、统计与对比基线

| 名词 / 缩写 | 一句话大白话解释 | 在本课题里的具体含义 |
| :--- | :--- | :--- |
| **IoU 与 `AP@0.5`** | IoU 是预测框与真实框的交并比；`AP@0.5` 是 IoU ≥ 0.5 时的综合检测平均精度 | 衡量整张图综合检测准不准（越高越好） |
| **`ASR`（定向攻击成功率）** | 专门盯着被攻击者动手脚的那批目标，算其中有多少真的被删掉或造假成功 | 局部攻防最直观的安全硬指标（**越低越安全**，本文压至 **`4.3% / 32.1%`**） |
| **FPR / TPR / AUROC** | FPR = 误报率（把好车冤枉的比例）；TPR = 检出率（抓住坏车的比例）；AUROC = 不依赖具体阈值的综合区分能力（`0.5` 瞎猜、`1.0` 满分） | 用来客观衡量检测器本身优劣，剥离人为调阈值偏见 |
| **客观盲区召回率** | 对“本车激光点数 ≤ 5 且单车推理漏检”的 583 辆纯盲区真车的检出比例 | 纯单车严格 `0%`，专门证明细粒度软门控比整车拒绝多保住了多少补盲车 |
| **10 Hz 实时红线 / P95 延迟** | 激光雷达每秒转 10 圈，单帧处理必须 `< 100 ms`；P95 是最慢 5% 帧的耗时上限 | 本文均值 **`69.9 ms`**（P95 `79.3 ms`）稳达标，`ROBOSAC` `190.9 ms` 严重超时 |
| **Block-Bootstrap 95% CI** | 按整条视频序列为单位重复抽样 2,000 次算出来的 95% 置信区间 | 比按单帧抽样更严格，杜绝相邻帧高度相关带来的虚假统计显著 |
| **`ROBOSAC` / `LUCIA` / `HetShield` / `WholeDrop`** | 4 个核心对比基线：前两个是同构顶会 SOTA，第三个是 2026 异构防御，第四个是同检测器的整车踢除消融对照 | 完整覆盖“同构框共识 + 同构特征投票 + 异构时空门控 + 整车级消融”全谱系 |
