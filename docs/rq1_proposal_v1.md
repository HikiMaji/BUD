## 0. 课题整体定位与研究点一在全篇中的角色

- **学位论文大题目**：《面向开放异构车联网的不确定性解耦与可信协同感知研究》
- **学院与学科要求**：东南大学网络空间安全学院（兼具车联网开放异构协同感知前沿性与对抗安全防御核心立意）
- **与同门方案的严格区分边界**：
  - 同门聚焦**封闭同构车联网**（统一传感器模态、相同骨干网络与稠密 BEV 特征分布），研究单恶意源特征生成式修复与外部设施辅助的合谋抑制。
  - 本课题聚焦**开放异构车联网（Open Heterogeneous V2X）**——协作车辆搭载不同线束/规格传感器（如 64 线高配 LiDAR、32 线中配 LiDAR、16 线稀疏低配 LiDAR 等）与异构私有三维点云编码器（如柱状体素编码 `PointPillars`、三维稀疏卷积编码 `SECOND`、三维体素网格编码 `VoxelNet/PIXOR` 等），通过向统一**共享协议域（Shared Protocol BEV Space）**映射实现中层特征协同。本课题明面上与机理上均**不讨论路侧辅助与否**，亦不退回贫瘠的纯二值目标框计数或底层激光雷达自由空间射线裁剪，而是直击开放异构中层协议空间里**“良性异构不确定性与恶意对抗扰动深度纠缠”**这一核心安全瓶颈。
- **全篇三点递进关系与预开题重点**：
  1. **【研究点一（本方案深化对象，预开题核心实证支撑点）】**：**面向开放异构协同的有界协议对齐与双源不确定性解耦融合方法**——在协议域表征与单帧协同融合层，解决异构适配器放大对抗扰动、共训置信度物理语义混杂、以及传统同构一致性防御在开放异构下“高误报误杀良性异构弱车 vs 宽阈值放任特征污染攻击”的两难困局，形成兼具**良性异构精度增益（Clean AP）**与**抗特征污染鲁棒性（Attacked AP）**的完整闭环。
  2. **【研究点二（后续展开）】**：面向自适应高置信伪装与多源异构合谋的证据冲突核验方法。
  3. **【研究点三（后续展开）】**：能力-信誉双轨空时演化的鲁棒协同感知机制与系统验证（应对跨帧渐进式平滑擦除与信誉投毒攻击）。

## 1. 现有方案不足深度分析

围绕开放异构车联网中层特征协同感知与安全防御，现有代表性工作可分为两条技术脉络，但二者在交叉地带均存在结构性缺陷：

### 1.1 开放异构协同感知网络：缺乏安全内生性，且无约束适配器与耦合置信度成为脆弱放大器
以 `MPDA` (AAAI'23)、`HEAL` (ICLR'24)、`PnPDA` (ECCV'24) 及 `STAMP` (ICLR'25) 为代表的开放异构框架，通过后向对齐（Backward Alignment）或轻量级协议适配器（Adapter-Reverter）将异构编码器特征映射至共享协议 BEV 空间，再经点积自注意力（`AttFusion`）或空间置信度门控（`Where2comm`）完成融合。其不足体现在三方面：
1. **无约束确定性适配器放大跨域扰动与稀疏伪影**：现有协议适配器由无谱约束的卷积或 ConvNeXt 块堆叠而成，其雅可比矩阵最大奇异值（局部 Lipschitz 常数）不受控制。最新研究 `HetPoison` (2026) 已证实“异构性天然防攻击”系假象；当恶意协作者注入单步/迭代对抗特征扰动（或传感器出现极端噪点）时，无约束适配器不仅无法阻隔扰动，反而因高奇异值通道响应将局部扰动非线性扩散放大为大面积协议空间伪影。
2. **全图均等分布对齐忽视前景稀疏性，遗留显著异构残差**：激光雷达 BEV 空间中超过 90% 网格为空背景，异构编码器（如基于 2D 柱状散射的 `PointPillars` 与基于 3D 稀疏卷积 `spconv` 的 `SECOND`）在空背景与前景边缘处的特征范数及纹理分布差异悬殊，简单对齐在远距稀疏区仍遗留显著跨模型域偏移残差。
3. **检测头共训的单维置信度物理语义错位且易被劫持**：以 `Where2comm` 为代表的置信度门控直接使用分类头输出 $\max \sigma(\text{cls\_head}(F))$ 作为空间权重。该指标将“目标存在概率（Foregroundness）”错误等同于“观测可靠性（Reliability）”——一方面，近距清晰无车的空地分类分数极低，却并非观测不可靠；另一方面，恶意目标伪造攻击（Spoofing）会直接拉高伪造区的分类置信度从而骗取最高融合权重，而目标擦除攻击（Removal）压低前景置信度或通过注意力键向量劫持（`LUCIA/SOMBRA` USENIX'25）压制本车自身清晰特征。

### 1.2 现有协同感知安全防御：依赖强同构假设，在开放异构下陷入“高误报误杀—高漏报穿透”死局
以 `ROBOSAC` (2023)、`LUCIA` (USENIX'25)、`CP-uniGuard` (2026, 基于 PASAC 抽样共识与检测一致性损失 CCLoss)、`GLST` (2026) 为代表的安全防御机制，核心思想是检验协作者与本车（或多数节点）在特征空间或检测框空间的一致性。当直接部署于开放异构车联网时，面临三大失效机制：
1. **良性异构不确定性与恶意对抗扰动深度纠缠导致高误报（False Quarantine）**：低线束协作者（如 16 线稀疏 LiDAR）在中远距离存在天然的**物理观测退化（偶然不确定性 Aleatoric Uncertainty）**，跨架构协作者（如 `SECOND` / 粗体素编码器）在协议映射后存在固有的**跨模型表征微偏移（认知不确定性 Epistemic Domain Uncertainty）**。同构防御使用统一尺度度量跨车差异，将上述良性异构分歧误判为恶意攻击。若维持严格门限，大量良性异构车辆被整车拉黑剔除，丧失协同补盲收益；若放宽自适应门限以兼容异构残差，恶意特征擦除与伪造扰动便趁虚穿透防线。
2. **本车盲区与共视核验区未加区分，直接残差比对扼杀“远端/遮挡补盲”核心价值**：在交叉口遮挡或本车远距盲区，本车特征为弱背景响应，而近距良性异构协作者传来强前景目标特征，此时跨车特征残差 $\|Z_{\text{ego}} - Z_i\|_2$ 天然巨大。缺乏双边不确定性校准的残差过滤会恰恰把最具价值的盲区补盲特征当作异常抹除。
3. **整车级硬剔除与多次检测头重推理开销过高**：`ROBOSAC` 与 `CP-uniGuard (PASAC)` 需对不同协作者子集反复执行特征融合与检测头前向传播以计算 `CCLoss`，计算延迟随协作者数量成倍增长；且整车级二值去留（0/1 Hard Rejection）一刀切丢弃了良性弱配车在近距高密度视区的有效观测。

## 2. 想要解决的核心科学问题与威胁模型

### 2.1 核心科学问题
在单次前向推理预算且无需任何攻击样本先验训练（Attack-Agnostic Training）的前提下，**如何在开放异构协同感知的共享协议空间中，限制跨域扰动的传播放大，并将“传感器物理退化偶然不确定性”、“跨架构表征认知偏移”与“恶意对抗特征篡改”显式解耦，从而在既不误杀良性异构协作者、又不牺牲本车盲区补盲能力的同时，精准抑制恶意特征擦除与伪造攻击？**

### 2.2 系统设定与威胁模型（Threat Model）
- **系统设定**：场景中存在本车（Ego，搭载标准 64 线 LiDAR 与基准 `PointPillars` 骨干，自身传感器与计算栈可信，但其物理视野受距离衰减与遮挡限制）与 $K$ 辆开放异构协作车（搭载 64/32/16 线等不同物理线束传感器，以及 `PointPillars`、`SECOND` 3D 稀疏卷积、`VoxelNet/Coarse-Pillar` 等异构编码器）。各协作者通过各自的发送端协议适配器 $\mathcal{A}_i$ 将特征映射至统一维度共享协议空间 $Z_i \in \mathbb{R}^{C_p \times H_p \times W_p}$ 发送给本车，并附带标准 V2X 通信位姿 $T_i$ 与基础传感器量程/线束类型标识 $m_i$。
- **攻击者能力与目标（研究点一聚焦范围）**：
  - 协作网络中存在至多 $M$（研究点一重点验证单源及非合谋恶意协作者，多源协同合谋与高阶自适应伪装留归研究点二递进）个被攻陷的异构或同构恶意节点；
  - 恶意节点可在发送协议特征 $Z_i$ 上施加有界范数或局部区域的恶意扰动 $\Delta Z_i$（涵盖：① **基于梯度的迭代/单步目标擦除攻击 Object Removal Attack**——企图抹除本车或协同视野内的真实车辆制造漏检碰撞风险；② **局部高响应特征伪造攻击 Ghost Spoofing Attack**——企图在空旷车道注入虚假车辆引发幽灵刹车；③ **跨异构迁移特征污染攻击 Cross-Architecture Transfer Perturbation**——模拟 `HetPoison` 在代理异构分支上生成的迁移扰动）。
  - **严格约束（遵循历史教训）**：本防御模型在训练阶段**完全不接触任何攻击样本（Zero Adversarial Training）**，仅使用正常开放异构协同数据训练；门限与温度超参数仅在验证集（`validate`）按固定校准准则确定一次，在未见测试集（`test`）上全程冻结评测。

## 3. 两大核心技术难点

1. **难点一：开放异构协议对齐中“跨域扰动非线性放大”与“双源不确定性物理语义混杂”的表征难题**
   异构点云编码器的特征尺度、稀疏模式与感受野各异，轻量级适配器在弥补跨架构域鸿沟时极易形成大奇异值病态映射，导致输入端微弱扰动或稀疏噪声在协议域剧烈扩散；同时，在不依赖恶意样本监督的条件下，如何从协议特征与通信几何中解耦出互不干扰的“物理观测偶然不确定性（由点云稀疏/视距决定）”与“流形偏离认知不确定性（由跨域未对齐或对抗分布外特征决定）”，缺乏可解析的建模机制。
2. **难点二：非对称视野与异构能力代差下“盲区有效补盲保留”与“局部恶意篡改抑制”的判别两难**
   在共视区，良性 16 线弱配车或异构模型车因物理稀疏和域微偏移与本车产生正常分歧；在本车遮挡/远距盲区，良性协作者因近距清晰观测到目标也会与本车背景特征产生剧烈差异。传统单边残差或全局一致性判据无法区分“良性弱车退化”、“良性近距补盲”与“恶意对抗擦除/伪造”，极易陷入误拒良性补盲信息或漏放恶意特征的泥潭。

## 4. 核心创新点（研究点一包含 2 个子创新点）

1. **创新点 1.1：提出谱范数有界的前景感知异构协议对齐与物理-流形双源不确定性内生解耦机制**
   设计逐层可控谱归一化的协议域分布对齐适配器（LB-FPA），从理论上收紧异构特征映射的局部 Lipschitz 上界以阻断对抗扰动跨域放大，并结合冻结基准骨干实现低开销异构接入；进一步在接收端构建**物理几何锚定的偶然不确定性分支**（由训练期局部点云密度真值无偏监督，并在推理期受收发相对距离物理下界包络约束）与**良性协议原型流形重构驱动的认知不确定性分支**，实现无需攻击先验的双源不确定性显式解耦。
2. **创新点 1.2：提出双边异构不确定性白化校准与流形净化协同的网格级软门控融合算法**
   打破传统同构硬阈值整车剔除范式，构建同时融合本车与协作者双边偶然不确定性及跨域基线方差的**非对称白化冲突度量**，结合共视核验域（Co-visible Verification Zone）分位数帧级可信度审计与协议流形投影净化，实现“良性稀疏退化降权容忍、本车盲区高确定性补盲无损放行、共视与流形异常特征精准软屏蔽”的单次前向鲁棒融合。

## 5. 提出的完整算法体系与各模块作用（`BUD-Fusion`: Bounded Uncertainty-Disentangled Collaborative Fusion）

整体框架由**三个紧密咬合的算法模块**组成，端到端运行于统一协议 BEV 空间 $\mathbb{R}^{C_p \times H_p \times W_p}$（在 OPV2V 标准设定下，$H_p = 100, W_p = 352$，对应 $0.8\text{m} \times 0.8\text{m}$ 物理网格，$C_p = 384$ 匹配多尺度金字塔拼接维度）：

### 算法模块一：谱范数有界的前景感知协议分布对齐器（LB-FPA）
- **结构设计**：
  设本车基准模型（64 线 `PointPillars`）的骨干与检测头参数 $\Theta_{\text{ref}}$ 预训练后**保持冻结**（确保本车单车感知与同构基准性能零退化，符合 `HEAL` / `STAMP` 开放可扩展范式）。对于第 $m$ 类异构智能体（如 `SECOND` 3D 稀疏卷积编码器、粗粒度体素编码器或低线束点云编码器），其原生多尺度 BEV 特征为 $F_i^{\text{raw}} \in \mathbb{R}^{C_m \times H_p \times W_p}$。设计带残差瓶颈与逐层缩放谱归一化（$\gamma$-SpectralNorm）的协议适配器 $\mathcal{A}_m$：
  $$\tilde{W}_l = \gamma \cdot \frac{W_l}{\sigma_{\max}(W_l)}, \quad Z_i = \mathcal{A}_m(F_i^{\text{raw}})$$
  其中通过幂迭代法（Power Iteration）实时约束每层卷积算子的谱范数不超过 $\gamma$（如 $\gamma \in [1.0, 1.5]$），从而使整个适配器的 Lipschitz 常数满足 $\text{Lip}(\mathcal{A}_m) \le \gamma^L$。
- **前景感知后向对齐损失**：
  为克服 90% 空背景网格对异构分布对齐的稀释，利用真值 3D 框投影生成前景高斯权重图 $M_{\text{fg}}(x,y) \in [0, 1]$，构造前景增强协议对齐损失与冻结检测头任务协同损失：
  $$\mathcal{L}_{\text{align}} = \frac{1}{H_p W_p} \sum_{x,y} \big(1 + \alpha_{\text{fg}} M_{\text{fg}}(x,y)\big) \Big( \| Z_i(x,y) - \text{sg}(Z_i^{\text{teacher}}(x,y)) \|_1 + \big(1 - \cos(Z_i(x,y), \text{sg}(Z_i^{\text{teacher}}(x,y)))\big) \Big) + \mathcal{L}_{\text{det}}\big(\text{Head}_{\text{ref}}(Z_i), Y\big)$$
  其中 $Z_i^{\text{teacher}}$ 为同一时刻该车位置处 64 线冻结基准编码器提取的协议锚点特征，$\text{sg}(\cdot)$ 表示停止梯度。
- **核心作用**：① 实现任意异构骨干特征与冻结基准协议空间的像素级语义对齐；② 严格抑制输入端稀疏噪声或对抗扰动在适配器内部的奇异值爆炸放大。

### 算法模块二：物理几何锚定与流形原型驱动的双源不确定性解耦器（DUID）
在接收端（本车坐标系下），对经位姿变换对齐后的每辆车（含本车 $i=0$ 与协作者 $i \in \{1,\dots,K\}$）协议特征 $Z_i \in \mathbb{R}^{C_p \times H_p \times W_p}$ 内生解耦出两张空间不确定性图：

1. **物理几何锚定的模态偶然不确定性分支 $\sigma_{\text{alea}, i}^2(x,y)$**：
   - **训练期无偏物理真值构造**：统计第 $i$ 辆车在每个 $0.8\text{m}\times 0.8\text{m}$ 协议网格内的实际激光雷达点云落入数量 $n_i(x,y)$，定义对数归一化物理观测密度 $\rho_i(x,y) = \min\big(1, \frac{\ln(1 + n_i(x,y))}{\ln(1 + N_{\text{ref}})}\big)$（取 $N_{\text{ref}}=32$），则物理偶然退化真值为 $u_{\text{alea}, i}^*(x,y) = 1 - \rho_i(x,y) \in [0, 1]$。
   - **距离-模态几何输入与物理下界锚定**：在推理时接收端无需原始点云，而是根据协作者位姿精确计算每个网格到协作者 $i$ 传感器中心的相对距离 $d_i(x,y) / R_{\max}$、视角方向 $(\cos\theta_i, \sin\theta_i)$ 及传感器线束编码 $e(m_i)$，与特征局部统计量（通道均值、标准差、$L_2$ 范数，对特征主体施加梯度隔离或轻量化卷积）拼接预测 $\hat{u}_{\text{alea}, i}(x,y) \in (0, 1)$，并叠加由训练集统计标定的传感器距离物理退化下界包络 $\underline{u}_{\text{phys}}(d_i(x,y), m_i)$：
     $$\sigma_{\text{alea}, i}^2(x,y) = \max\Big( \hat{u}_{\text{alea}, i}(x,y),\; \underline{u}_{\text{phys}}\big(d_i(x,y), m_i\big) \Big)$$
   - **核心作用**：准确刻画“谁在哪块区域看得清、谁因距离远或 16 线稀疏看不清”；且由于物理距离下界 $\underline{u}_{\text{phys}}$ 由几何位姿锁定，恶意节点绝无法在远距盲区通过刷高特征幅值伪装成“近距零不确定性清晰观测”。

2. **良性协议原型流形驱动的跨域认知不确定性分支 $\sigma_{\text{epis}, i}^2(x,y)$**：
   - **结构设计**：在协议通道上构建包含 $M_c$（如 $M_c = 64$）个可学习正交基原型的良性协议记忆码本（Protocol Manifold Codebook）$P \in \mathbb{R}^{M_c \times C_p}$，以及轻量投影器 $Q = W_q \text{LayerNorm}(Z_i(x,y))$。通过温度缩放注意力聚合码本原型重构特征：
     $$\hat{Z}_i^{\text{proj}}(x,y) = W_o \Big( \text{Softmax}\big(\frac{Q(x,y) P^\top}{\sqrt{d_k}}\big) P \Big)$$
   - **训练准则（纯良性无监督流形拟合）**：仅在良性训练集的协议特征上最小化重构误差 $\|Z_i - \hat{Z}_i^{\text{proj}}\|_2^2 + \lambda_{\text{orth}} \|P P^\top - I\|_F^2$。
   - **认知不确定性度量**：定义归一化流形重构残差为认知/分布外不确定性：
     $$\sigma_{\text{epis}, i}^2(x,y) = \frac{\big\| Z_i(x,y) - \hat{Z}_i^{\text{proj}}(x,y) \big\|_2^2}{\|Z_i(x,y)\|_2^2 + c_0}$$
   - **核心作用**：良性同构与已对齐良性异构特征紧贴协议码本流形，$\sigma_{\text{epis}}^2$ 稳定处于低值域；而旨在破坏检测头的对抗扰动（无论迭代梯度攻击还是跨模型迁移扰动）会破坏通道间固有共现结构，导致流形重构残差 $\sigma_{\text{epis}, i}^2(x,y)$ 显著抬升，且投影特征 $\hat{Z}_i^{\text{proj}}$ 天然具备对高频离群扰动的净化能力。

### 算法模块三：双边白化校准与共视审计耦合的网格级软门控融合（UCR-Fusion）
拿到本车 $(Z_0, \sigma_{\text{alea},0}^2, \sigma_{\text{epis},0}^2)$ 与各协作者 $(Z_i, \sigma_{\text{alea},i}^2, \sigma_{\text{epis},i}^2)_{i=1}^K$ 后，按三步完成单次前向安全融合：

1. **双边异构不确定性白化的局部跨车冲突分数**：
   在每个空间网格 $(x,y)$ 计算协作者 $i$ 与本车 $0$ 的白化特征分歧：
   $$D_i^{\text{cal}}(x,y) = \frac{\frac{1}{C_p}\big\| Z_0(x,y) - Z_i(x,y) \big\|_2^2}{\tau_a \big(\sigma_{\text{alea},0}^2(x,y) + \sigma_{\text{alea},i}^2(x,y)\big) + \tau_e \sigma_{\text{dom}}^2(m_i) + \epsilon}$$
   - **物理机理验证**：
     - 当本车被遮挡/远距看不清（$\sigma_{\text{alea},0}^2$ 高）而良性协作者近距看得清（$\sigma_{\text{alea},i}^2$ 低）时：分母因 $\sigma_{\text{alea},0}^2$ 大而自动宽容，**不会因本车盲区无响应而误杀良性协作者的补盲特征**！
     - 当本车近距看得清（$\sigma_{\text{alea},0}^2$ 低）而良性 16 线协作者远距点云稀疏（$\sigma_{\text{alea},i}^2$ 高）时：分母因 $\sigma_{\text{alea},i}^2$ 大而同样宽容，**不会将良性弱配车误判为攻击者**！
     - 当恶意节点试图抹除本车视野内的真车或在清晰共视区伪造目标时：$\sigma_{\text{alea},0}^2$ 低且 $\|Z_0 - Z_i\|_2^2$ 巨大，$D_i^{\text{cal}}(x,y)$ 剧烈升高！

2. **共视高确定核验域（Co-visible Verification Zone）的帧级可信折减审计**：
   定义双边清晰共视核验域 $\Omega_{\text{covis}, i} = \{ (x,y) \mid \sigma_{\text{alea},0}^2(x,y) < \theta_{\text{clear}} \;\land\; \underline{u}_{\text{phys}}(d_i(x,y), m_i) < \theta_{\text{reach}} \}$。统计协作者 $i$ 在共视核验域上的高分位数冲突度与全图高幅区流形异常度：
   $$s_i^{\text{frame}} = \text{Quantile}_{0.95}\big( D_i^{\text{cal}}(x,y) \;\big|\; (x,y)\in \Omega_{\text{covis}, i} \big) + \lambda_m \cdot \text{Quantile}_{0.98}\big( \sigma_{\text{epis},i}^2(x,y) \big)$$
   依据在验证集（`validate`）良性异构数据上按固定显著性水平（如 $\alpha = 5\%$ 误警预算）一次性标定的门限 $\tau_{\text{frame}}$，计算平滑软信誉门控因子：
   $$\eta_i = \sigma_{\text{temp}}\Big( -\kappa \big(s_i^{\text{frame}} - \tau_{\text{frame}}\big) \Big) \in (0, 1]$$
   （避免硬阈值抖动，良性异构车 $\eta_i \approx 1$，发动特征擦除/伪造的恶意车 $\eta_i \to 0$）。

3. **网格级精度加权与流形混合净化融合**：
   对协作者特征先按流形认知不确定性做自适应软净化 $\tilde{Z}_i(x,y) = (1 - \alpha_{\text{proj}}(x,y)) Z_i(x,y) + \alpha_{\text{proj}}(x,y) \hat{Z}_i^{\text{proj}}(x,y)$，再结合帧级可信度 $\eta_i$、网格局部异常门控 $g_i(x,y) = \exp\big(-\beta_d \max(0, D_i^{\text{cal}}(x,y) - \tau_{\text{grid}}) - \beta_e \max(0, \sigma_{\text{epis},i}^2(x,y) - \tau_{\text{epis}})\big)$ 与观测精度权重 $\pi_i(x,y) = (1 - \sigma_{\text{alea},i}^2(x,y) + \delta_0)$ 调制多车注意力融合权重（本车恒定锚点 $\eta_0 = 1, g_0 = 1$）：
   $$w_i(x,y) = \frac{\eta_i \cdot g_i(x,y) \cdot \pi_i(x,y) \cdot \exp\big(\frac{q_0(x,y)^\top k_i(x,y)}{\sqrt{C_p}}\big)}{\sum_{j=0}^K \eta_j \cdot g_j(x,y) \cdot \pi_j(x,y) \cdot \exp\big(\frac{q_0(x,y)^\top k_j(x,y)}{\sqrt{C_p}}\big)}, \quad Z_{\text{fused}}(x,y) = \sum_{i=0}^K w_i(x,y) \tilde{Z}_i(x,y)$$
   最终将 $Z_{\text{fused}}$ 送入冻结检测头 $\text{Head}_{\text{ref}}$ 单次前向输出 3D 检测框。

## 6. 实验底座、数据集划分、异构车队与评测设计

### 6.1 实验底座与运行环境
- **硬件与软件栈**：NVIDIA GeForce RTX 4090 (24GB)，基于服务器已核实的 `/root/miniconda3/bin/python`（PyTorch 2.0.0+cu118、`spconv 2.3.6`、`OpenCOOD` 核心算子库），所有新增代码、配置、权重与结果严格隔离存放于 `/root/autodl-tmp/proj_dir2_hetero_trust/`。
- **数据划分（严格父序列隔离，杜绝泄漏与重复调参）**：
  - **训练集（`train`）**：OPV2V 官方训练集 **20 条独立序列**（43GB），仅用于训练异构骨干、协议对齐适配器、偶然不确定性头与良性协议流形码本；
  - **验证校准集（`validate`）**：OPV2V 官方验证集 **6 条独立序列**（13GB），用于模型早停选择，并在纯良性开放异构设定下按预设 5% 分位数准则**一次性标定所有防御基线及本方法的检测门限**（严格执行共同校准原则，绝不为每个方法在测试集上挑最优门限）；
  - **未见终测集（`test`）**：OPV2V 官方测试集 **16 条独立序列**（18GB），全程冻结所有权重与门限，输出最终论文级指标。

### 6.2 开放异构车队配置（涵盖“跨网络架构异构 + 跨传感器物理线束异构”）
为全面还原真实开放车联网，构建包含 **4 类异构智能体画像（Agent Profiles）** 的混合协同池：
1. **Profile-A（本车 Ego / 同构高配基准）**：64 线 LiDAR + 细粒度 `PointPillars`（体素 $0.4\text{m}\times 0.4\text{m}$，预训练冻结锚点）；
2. **Profile-B（跨三维骨干架构异构）**：64 线 LiDAR + **`SECOND` 三维稀疏卷积骨干**（`MeanVFE` + `spconv VoxelBackBone8x` 三维体素卷积 + 高度压缩，特征生成机理与 2D Pillar 截然不同）；
3. **Profile-C（跨空间分辨率/体素编码异构）**：32 线物理俯仰环重采样中配 LiDAR + **粗粒度柱状编码分支（Coarse-Pillar / Multi-Res VFE，体素 $0.8\text{m}\times 0.8\text{m}$）**；
4. **Profile-D（极端物理受限弱配传感器异构）**：**16 线稀疏物理降采样 LiDAR**（按激光器俯仰角环每 4 环取 1 环，远距点云密度骤降 75%，复现低成本车载固态/低线束雷达的严重偶然退化）。

### 6.3 攻击威胁评测集（4 类代表性场景）
1. **Clean Open-Hetero（良性开放异构无攻击）**：检验各方法是否误杀良性异构协作者、能否充分挖掘异构补盲潜力提升 AP；
2. **PGD Feature Removal Attack（梯度目标擦除攻击，白盒/灰盒强攻击）**：恶意协作者针对协议特征施加多步/单步有界扰动（如 $\ell_\infty$ 预算 $\epsilon \in \{0.1, 0.25, 0.5\}$ 或相对能量比预算），最大化前景擦除损失以抹除真实目标；
3. **Targeted / Regional Ghost Spoofing Attack（局部高响应伪造鬼影攻击）**：恶意协作者在道路自由区域注入高置信前景伪特征模板或针对性伪造优化扰动，诱发大量假阳性框；
4. **Cross-Architecture Transfer Attack（`HetPoison`-style 单步跨异构迁移扰动）**：攻击者不知晓接收端内部门控参数，在自身代理检测头上单步前向生成目标抑制/干扰扰动并经异构适配器发送，检验无约束适配器 vs 有界 LB-FPA 适配器的扰动放大效应及防御泛化性。

### 6.4 公平对比基线与核心评价指标
- **对比方法（共 6 组）**：
  1. `No-Collab (Ego-Only)`：仅本车单车感知（协同感知下界）；
  2. `Unconstrained-AttFusion (HEAL/STAMP-style)`：无安全防护的开放异构协议对齐 + 标准自注意力融合；
  3. `Hetero-Where2comm`：使用检测分类头共训置信度进行空间门控的异构融合；
  4. `Homo-Def: ROBOSAC / PASAC-CCLoss`（复现 `CP-uniGuard` / `ROBOSAC` 核心检测框一致性损失判据，在 `validate` 集统一标定 95% 良性分位数门限）；
  5. `Homo-Def: Global-Feat-Residual`（基于全局协议特征余弦/欧氏残差的来源过滤防御，同样统一 95% 良性分位数校准）；
  6. `Ours (BUD-Fusion)`：本文提出的谱范数有界协议对齐 + 双源不确定性内生解耦 + 白化软门控融合（附完整逐模块消融：`w/o Spectral Bound`、`w/o Aleatoric Calibration`、`w/o Epistemic Manifold`）。
- **评价指标**：
  - **3D 目标检测主指标**：`AP@IoU=0.50`、`AP@IoU=0.70`（分别汇报 Clean 良性异构场景与各攻击场景下的 AP）；
  - **安全判别与误杀指标**：良性异构协作者误判抑制率（`Benign False Quarantine Rate, BFQR` ↓）与恶意协作者识别率 / 攻击权重压制率（`Malicious Suppression Ratio, MSR` ↑）；
  - **区域分层诊断指标（吸收项目历史教训）**：分别统计**共视核验域**与**本车弱视/遮挡补盲域**的召回率（Recall）与精确率（Precision），证明总体 AP 提升确实来源于“保住盲区真目标补盲 + 拦截假目标与擦除攻击”的真实物理机制！
  - **实时运行开销**：单帧端到端推理延迟（ms）对比。
